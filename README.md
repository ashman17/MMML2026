### Language-only analysis of MMSI-Bench

This analysis explores how question wording specifies the spatial problem, and what a model can answer without the images.

See [analyses/language/README.md](analyses/language/README.md).

The scripts read `MMSI_bench.tsv` and `MMSI_Bench.parquet` from `../MMSI-Bench/.analysis/`, or from the directory in `MMSI_DATA_DIR`.
