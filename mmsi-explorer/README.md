# MMSI-Bench Explorer

Double-click `start.command` to open the local visualizer.

The explorer contains all 1,000 MMSI-Bench questions with optimized image copies. It supports category, difficulty, text, and sorting filters, plus answer and reference-reasoning inspection.

Use **Overlap labeler** in the top bar to annotate the blinded 100-pair verifier-calibration sample. Labels are saved locally in the browser and can be exported as JSON.

The original downloaded dataset is stored as `MMSI_Bench.parquet` alongside this folder on the Desktop.
