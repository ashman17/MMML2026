# MMML2026

Research prototypes for MMSI-Bench multi-image spatial reasoning.

## Components

- `mmsi-explorer/`: local MMSI-Bench browser and overlap-annotation UI.
- `mmsi-ollama-baseline/`: Ollama-based baseline, inspection, and chat tools.
- `claim-extractor/`: two-stage atomic-claim and reasoning-dependency graph extraction.
- `proof-engine/`: falsifiable visual proof graph prototype and evaluation scripts.

Large datasets, generated images, model outputs, virtual environments, API keys,
and third-party model repositories are intentionally excluded.
